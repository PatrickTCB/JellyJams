# Contributing

I love open source software. It's why I use Jellyfin, and I am trying to pay
it forward a bit with this app.

However, I'm a solo dev, with an actual job, and a family. So while I welcome
any feedback, I can't guarantee that I'll accept any PRs or do features you
might want.

My goal with this app is to make the perfect Jellyfin music playing app
for me.

If Jelly Jams is close to what you want, but missing something then please
open an issue before putting the work in to a PR. There I'll be let you
know if it's something that I can do, something I'd accept a PR for, or
something that's best handled by you forking the project.

I've purposely gone with the most open license that the App Store will
allow.

## AI Use
I am a pretty heavy Ollama user. Swift and SwiftUI documentation is not always 
very good so I rely on both conversational interactions with models like Gemma4 
and code reviews.

Contributors who are using AI is totally fine, but include what you used it for
in your PR. This way I know where there might be extra attention required.

That said, if you submit a giant AI PR I will just close it. Making this app isn't 
my job, nor is it yours. So there's no way I can dedicate 40-60 hrs to do thorough 
review and testing of some huge change. And since this is a for fun project, I also 
don't want the stress of PR sitting open and un-reviewed for ages.
